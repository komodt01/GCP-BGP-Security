Technologies Used:

Google Cloud IAM:
Manages roles and permissions with least privilege.

Cloud Logging:
Stores audit logs, security logs, and VM/system logs.

Cloud Monitoring:
Provides alerting and performance visibility.

Cloud Asset Inventory:
Tracks configuration changes and resource posture.

VPC Firewall Rules:
Controls inbound and outbound traffic to resources.

Cloud Key Management Service (KMS):
Manages encryption keys for sensitive data.

Secret Manager:
Stores credentials and API keys securely.

Cloud DLP API:
Detects and classifies sensitive data in storage.

Compute Engine:
Runs security or monitoring VMs if needed.

Cloud Functions:
Supports serverless automation for security events.

Cloud Scheduler:
Runs scheduled scans or compliance checks.

Artifact Registry:
Stores images with vulnerability scanning enabled.
